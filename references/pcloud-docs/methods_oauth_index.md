# OAuth 2.0

pCloud supports [OAuth 2.0](http://oauth.net/) for authentication of all API requests.

After getting the bearer token the API methods could be called with the global parameter access_token.

\
\
You can also use the bearer token in the HTTP Authorization header. This is an example header:

\
Authorization: Bearer access_token\

With the current implementation the access tokens given from pCloud API **do not expire**.
